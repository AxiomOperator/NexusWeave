# NexusWeave Brand Details

## Brand Name
**NexusWeave**

## Tagline
**Connected code intelligence for AI agents**

## Brand Summary
NexusWeave is a fast, local-first engine that maps source-code relationships and delivers precise repository context through MCP. The brand should feel technical, precise, modern, and quietly powerful—built for developers and AI coding agents.

## Brand Positioning
NexusWeave helps AI coding agents understand codebases with precise, relationship-aware context.

## Core Brand Attributes
- **Connected**
- **Precise**
- **Local-first**
- **Agent-ready**

## Brand Keywords
- Graph-native
- Trustworthy
- Technical
- Surgical
- Modern

## Logo Concept
The NexusWeave mark is a woven **N** built from ribbon-like paths and connected nodes.

It represents:
- interconnected source-code relationships
- flow of context through a repository
- node-and-edge graph intelligence
- precise, agent-ready traversal across code structures

## Visual Motifs
- Node-and-edge geometry
- Woven ribbons
- Directed arcs
- Soft luminous gradients
- Dark technical surfaces with neon highlights

## Usage Guidance
- Prefer dark backgrounds for primary branded experiences.
- Use cyan-to-violet gradients for highlights and hero moments.
- Reserve teal for signal states, secondary accents, and supportive emphasis.
- Keep layouts minimal, technical, and high-contrast.
- Use the icon alone for app icons, avatars, and compact placements.
- Use the full wordmark for websites, deck covers, product headers, and documentation.

## Logo Usage Guidance
### Do
- Maintain generous clearspace around the logo.
- Use the full-color version on dark backgrounds.
- Use monochrome variants only when necessary.
- Keep the woven structure crisp and legible.

### Do Not
- Stretch or distort the logo.
- Change the brand colors arbitrarily.
- Place the primary logo on visually busy backgrounds.
- Add extra effects that compete with the icon’s glow and structure.
